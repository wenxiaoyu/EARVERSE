# Design: ai-assessment-pronunciation

## Context

现测验先显示单词再播发音（提示效应），且题源对所有人/场景固定；产品无发音维度。用户决策：**测验全程交给 AI 掌控**（AI 出题、给答案键、判卷、出画像），规则仅作管道；发音**先做可懂度（A 方案）**并预留音素级升级；发音与测验重做**同批纳入 P0**，跟读训练放 P1。

## Goals / Non-Goals

**Goals:**
- AI 全程驱动测验：出题→作答→判卷→画像，2 次模型调用完成。
- 先听后看 + 客观选择题，修复哑巴词汇测不准的问题。
- 测验纳入发音探测，画像新增发音维度（分场景）。
- 文本模型与音频供应商分离配置。

**Non-Goals:**
- 不做锚题/经验难度校准（用户明确选择纯 AI，接受跨次可比性变弱）。
- 首版不做音素级（GOP）评分，仅预留接口。
- 不做多用户鉴权、不做云端同步。

## Decisions

### D1：两次调用的 AI 测验
- **选择**：① 开考一次调用生成整份题单（含难度/选项/答案键/评分要点）；② 收卷一次调用综合作答日志产出画像。
- **理由**：每题都转模型延迟不可用；两次调用既保证"AI 掌控内容与判断"，又可接受延迟/成本。
- **替代**：逐题 agent 循环（保真但慢）、固定题源（违背需求）。

### D2：先听后看 + 客观选择题
- 听音阶段不显示原文；四选一中文，对错 = 选项==答案键；没听出才露词并问"看着是否认识"。
- **理由**：消除提示效应，让"哑巴词汇"可测；选择题比自报客观。
- **替代**：自由输入（需 ASR/判分，重）作为可选补充。

### D3：四态归类交给 AI
- 画像四态、盲区、弱点、置信度由 AI 收卷时判定；规则不改判。
- **理由**：遵循"AI 全程掌控"；规则仅执行与校验。

### D4：跨次一致靠画像上下文（不用锚题）
- 开考把上一版画像摘要喂给 AI，AI 相对上次校准。
- **代价**：无固定刻度，跨次可比性弱于锚题方案——已知并接受。

### D5：发音按可懂度评分 + 音素级预留
- A 方案：ASR 转写 vs 目标文本差异 → AI 推断音素问题（如 θ→s），给证据+置信度。
- 接口：`score_pronunciation(audio, target, level)`，未来 `level=phoneme` 接强制对齐/GOP。
- **替代**：直接上 Azure 发音评估（准但成本/依赖高）。

### D6：文本/音频供应商分离
- `llm`（文本，可 DeepSeek）与 `audio`（ASR/TTS/发音，需 OpenAI/Azure）各自 base_url/key/model。
- **理由**：DeepSeek 聊天端点无音频；发音必须有音频供应商。

### D7：降级不静默
- 无文本模型 → 用种子题 + 本地画像模板，标注来源。
- 无音频供应商 → 发音探测提示并跳过，其余照常；不伪造评分。

### D8：数据契约（AI 返回）
```
题单: {plan_note, items:[{w,zh,ex,difficulty,difficulty_reason,play_text,options[4],answer_index,tag}]}
画像: {verdict, vocab{word:state}, blind_spots[], avoidance[], weaknesses[], pronunciation{score,issues[]}, confidence, next_plan}
```

## Risks / Trade-offs

- [AI 难度无统一刻度 → 跨次可比性弱] → 已知接受；用上版画像上下文缓解；后续可加锚题。
- [AI 答案键/释义可能有误] → 校验层（选项唯一、索引合法、释义非空）+ 重试；异常题丢弃。
- [两次调用延迟/成本] → 题单缓存按(场景,档位)；max_tokens 分层。
- [音频供应商依赖] → 明确提示 + 降级；文档说明。
- [发音可懂度评分的误报] → 给置信度；低置信不下狠结论；后续升级音素级。

## Migration Plan

- 画像新增 `pronunciation` 维度（缺省空，向后兼容）。
- 移除旧"先看词"测验流程；旧测验会话不保留。
- 配置新增 `audio` 段；旧 `llm` 配置继续可用。

## Open Questions（已定）

- 音频供应商：**以 ASR 评分为准（可懂度）**，不建音素级；音频/ASR 走 OpenAI 兼容的 `audio` 配置（可选 Azure）。
- 自由输入释义：**保留为选择题的补充**，由 AI 判分。
- 成本不作为约束，以效果为先。
- 播放发音：**用浏览器 TTS**（保留音色/语速/音高/口语化设置）；DeepSeek 只负责 **ASR（发音评估）**，不接管播放。
