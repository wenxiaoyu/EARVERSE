## Context

产品已有 24 个训练场景（`domain`）与独立画像轨道；Today 是 4 步 60 分钟工作台。背诵需要成为**独立能力**：随时可用、不受 Today 节奏约束，但仍要复用场景、画像、LLM、ASR，并产生可回流的学习数据。

## Goals / Non-Goals

**Goals**
- 用户进入「背诵」即可拿到一篇适合自己水平的文章，完成「听懂 → 背诵 → 评分 → 复盘」闭环。
- 提示分级可量化，评分可解释，复盘能指导下一次。
- 数据回流画像，形成「漏词 → 下次复现 → 难度自适应」的飞轮。
- 无 Key 时可降级演示。

**Non-Goals**
- 不做用户自带文章（v1 仅 AI 出篇）。
- 不做逐音素强制对齐/韵律可视化。
- 不把背诵塞进 Today 或改变 60 分钟结构。
- 不做社交分享、排行榜。

## Decisions

### D1 独立导航，第 3 位
导航变为 `今天 / 测验 / 背诵 / 实战 / 报告 / 设置 / 关于`，2 字文案与现有风格一致；图标为「书页 + 声波」。

### D2 场景跟左侧全局训练场景
背诵页不重复造场景选择器，直接用 `domain`。切换左侧场景后，背诵页重新加载该场景的每日推荐与历史。

### D3 每日推荐 + 换一篇
`(domain, level, date)` 唯一缓存一篇 `kind=daily`；`POST /generate` 生成 `kind=manual`，不覆盖每日推荐。当天重复进入看到同一篇，保证「每天一篇」的仪式感；想练更多可换一篇。

### D4 难度三轴与 L1–L5
- 三条轴：词数/句长、词汇抽象度、语流密度（连读弱读）。
- 默认从 L2 起步；画像有历史时用画像 level。
- 升级：最近 2 次完整度 ≥85% 且提示 ≤L1 → +1；降级：最近 1 次完整度 <60% → -1；夹紧 1–5。
- 每次只动一条轴，避免一次跳太难。

### D5 提示阶梯 L0–L2
- L0 无提示
- L1 每句首词 + 连接词
- L2 每句内容词（名词/动词/形容词/副词），虚词隐藏（默认推荐）
- 「显示整句」不算提示，算放弃重来，本次不计分。
- 独立性 = `100 - 25 × hint`（L0=100 / L1=75 / L2=50），只用于展示和升级判断，不改原始分。

### D6 对齐评分（原文已知）
转写与原文都做归一化（小写、去标点、常见缩写展开），用 `SequenceMatcher` 对齐；替换词允许模糊匹配（相似度 ≥0.75 且长度接近）。
- 完整度 = 匹配词 / 原文词（模糊匹配计 0.5）
- 准确度 = 1 - (替换 + 漏 + 多 + 0.5×模糊) / 原文词
- 流利度 = wpm 落在等级目标带得 100，偏离按 1.5/词扣分
- 独立性 = 100 - 25×hint
- 综合 = 0.4×完整 + 0.3×准确 + 0.15×流利 + 0.15×独立
- 漏句：句内覆盖率 <60%；漏语块：语块词覆盖率 <60%。

### D7 复盘结构化
AI 返回 `summary / wins / misses / pron_issues / drill / next`；失败或未配 Key 时用确定性本地复盘，保证可用。错音写入 `recent_pron_issues`，漏语块写入 `weak_chunks`。

### D8 存储与保留
- `recitations`：文章 JSON（标题、句子、语块、目标词、why、level、date、kind）。
- `recitation_attempts`：转写、四项分、diff、复盘、提示档、时长、录音路径。
- 历史保留最近 30 次/场景；录音 WAV 保留 7 天，过期文件启动/写入时清理。

### D9 降级
未配 LLM：用 `seed/recitations.json` 对应等级文章 + 本地复盘。
未配 ASR：评分接口返回 409 与清晰中文提示，页面提示去设置；不影响「听懂/提示」阶段。

## Risks / Trade-offs

- **ASR 对背诵的漏词可能误判**：用模糊匹配 + 允许小差异；展示「转写」让用户自己判断。
- **流利度没有停顿检测**：v1 用 wpm + 时长；v2 再做静音段分析。
- **每日推荐缓存可能让用户觉得重复**：提供「换一篇」，并显示「今日推荐」标识。
- **新场景画像为空**：L2 起步，前几次以稳定体验为主。

## Migration

`ensure_domain` 对每个场景回填 `recitation` 默认结构（level 2、空历史），旧画像无需手工迁移。
