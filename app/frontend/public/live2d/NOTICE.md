# Live2D models & runtime

This directory vendors Live2D sample models for local demonstration:

- `mao/` — Live2D Cubism 4 sample model "Mao"
  - Source: https://github.com/Live2D/CubismWebSamples/tree/develop/Samples/Resources/Mao
- `lib/live2dcubismcore.min.js` — Live2D Cubism Core (C) Live2D Inc.
- `lib/live2d.min.js` / `shizuku/` — Cubism 2.1 sample kept as fallback reference

These are sample assets under Live2D's sample licenses. Replace them with your own licensed model before commercial distribution.
